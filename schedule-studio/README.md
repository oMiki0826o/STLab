# Schedule Studio

一個可直接部署至 GitHub Pages 的繁體中文課表產生器，不需要後端。

### 已實作

- 編輯星期一至星期五／六／日的課表，每天 4–12 節。
- 設定課表名稱、學期註記、第一節開始時間、節長及下課時間。
- 點擊格子新增／修改／刪除課程，支援教室與教師備註及課程分類。
- 三種配色主題。
- 自動儲存於目前瀏覽器的 localStorage。
- 下載 PNG、匯出／匯入 JSON 備份。
- A／B 週切換；兩週課程分開儲存，可各自預覽與匯出。

### 開啟與部署

直接打開 `index.html` 即可使用。發布到 GitHub Pages 時，將此資料夾的檔案放在倉庫根目錄，設定 `Settings → Pages → Deploy from a branch → main / root`。
